# Misty Casa Website

A responsive, single-page website for Misty Casa, built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Included sections

- Hero and navigation
- Destination gallery: Wayanad, Munnar, Alleppey, Coorg, and Ooty
- About Misty Casa
- Getaway/package enquiry cards
- Enquiry form that prepares an email in the visitor's default mail app
- WhatsApp contact link
- Instagram links for [@mistycasa.in](https://www.instagram.com/mistycasa.in?dlrf=MXhkMm1iNHYza3BxMg==)

## Deployment

This is a static website and can be deployed using Vercel, Netlify, or GitHub Pages. For Vercel, import this repository and use the repository root as the project root.

## Notes

- Destination photography and web fonts load from external services, so an internet connection is needed for those assets.
- The enquiry form uses a `mailto:` link; it does not send form data to a server. Configure a real form endpoint or business email if server-side enquiry handling is needed.
- Package descriptions are illustrative. Confirm actual offers and availability before publishing them as bookable deals.
